Syntax reference: link

Demo songs: Play | Sample MML


One row per allocated chip channel (FM / PCM / SAMPLER / KS, max 26; extras ignored). Lit keys = notes currently sounding on that channel — tracks routed to the same %module,%number share a row and stack polyphonically. White tick = live pitch (follows bends, vibrato-free glide, portamento slides); yellow outline = portamento/bend target; right meters: pitch bend, pan, volume.
